# Правила игры TES Idle

## Общие положения

TES Idle — это автоматическая RPG (auto-rpg) в мире The Elder Scrolls. Герой autonomously исследует мир, сражается, отдыхает и торгуется. Игрок наблюдает за его приключениями через нарративный дневник и может вмешиваться как «бог».

## Игровой тик (Game Tick)

Герой совершает одно действие за один «тик».

- **Онлайн:** 15–60 секунд (случайно)
- **Офлайн:** 60–900 секунд (1–15 минут)

Мотивация быть онлайн: более частые действия = больше прогресса.

## Состояния героя (State Machine)

| Состояние | Описание |
|-----------|----------|
| idle | Ожидает (стартовое) |
| exploring | Исследует локацию |
| fighting | Сражается с монстром |
| resting | Отдыхает, восстанавливает HP |
| shopping | Торгуется на рынке |
| looting | Обыскивает добычу |
| traveling | Путешествует между локациями |
| socializing | Общается в таверне |
| dead | Мёртв (respawn через resting) |

Переходы между состояниями определяются:
- Потребностями (голод, усталость, мораль)
- Настроением
- Локацией
- Случайностью

## Потребности (Needs)

| Параметр | Эффект | Изменение за тик |
|----------|--------|-----------------|
| Голод (hunger) | При >80%: -мораль, -настроение | +0.5–2.0 |
| Усталость (fatigue) | При >80%: -мораль | +0.3–1.0 |
| Мораль (morale) | Влияет на настроение | -0.5 до +0.5 |

## Настроение (Mood)

Рассчитывается автоматически:
```
mood = 50 + (100 - hunger) * 0.2 + (100 - fatigue) * 0.15 + morale * 0.15
```

Влияет на:
- Типы нарративов (мысли героя)
- Шансы на социализацию

## Бой (Combat)

- Урон героя: `attack + random(-3, 5) - monster.defense`
- Урон монстра: `random(monster.attack_min, monster.attack_max)`
- Победа: +XP, +золото, +1 к убийствам
- Проигрыш: потеря HP
- Смерть: потеря 10% золота, респавн

## Уровни и прогресс

- Начальный XP до следующего уровня: 100
- Формула: `xp_to_next = xp_to_next * 1.5` после каждого уровня
- При апа: +10 max HP, +5 max MP, +2 attack, +1 defense

## Действия бога (God Actions)

| Действие | Эффект | Кулдаун |
|----------|--------|---------|
| Вдохновить | +15 морали, +10 настроения | 5 мин |
| Наказать | -10 морали, -10 настроения | 5 мин |
| Исцелить | +30 HP | 5 мин |
| Погода | Визуальный эффект | 5 мин |

## Пантеон (Leaderboard)

Три категории рейтинга:
1. **Убийства** — общее количество убитых монстров
2. **Золото** — общее заработанное золото
3. **Время** — время в игре (в секундах)

Обновляется в реальном времени.

## Локации

Стартовые локации:
1. **Ривервуд** — деревня, уровень 1–5, низкая опасность
2. **Вайтран** — столица, уровень 3–12, средняя опасность

## Предметы

Типы:
- **Расходники** (consumable) — зелья, еда, свитки
- **Экипировка** (equipment) — оружие, броня, кольца, амулеты
- **Мусор** (junk) — только для продажи

Редкость: common → uncommon → rare → epic → legendary

## Предложения игроков

Игроки могут предлагать:
- Нарративы (записи в дневник)
- Монстров
- Квесты
- Предметы
- Мысли героя

Предложения проходят модерацию в админ-панели.

## Технические ограничения

- Максимум записей в дневнике: 200 (пагинация)
- Максимум инвентаря: 20 слотов
- Один герой на пользователя
- База данных: PostgreSQL
- Backend: FastAPI (Python)
- Frontend: React + Tailwind CSS
