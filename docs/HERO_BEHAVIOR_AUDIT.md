При этом active_quest у Джозеца **всегда есть** (auto_accept), а decision_log показывает goal `complete_quest` с utility 0.928–1.0 в ~85% тиков, включая 3 часа ночи. Состояние: hp 101/260 (39%), **sp = 0**, золото 30 625.

## 2. Корневые причины

### A. «Тирания квеста» — activities математически недостижимы (критично)

1. `Pipeline.auto_accept_quest` берёт новый квест **в том же тике**, как завершён старый → активный квест есть 100% времени.
2. `Goal.eval_quest`: `base 0.7 + tenacity × 0.003` — **не зависит ни от HP, ни от усталости, ни от голода**. Для Джозеца: 0.7 + 0.207 = 0.907, с мозгом 0.928–1.0 — всегда.
3. Остальные потолки utility: fish/gather/steal/break_in ≈ 0.25–0.55; pet_care ≈ 0.2–0.4; shop ≈ 0.43; loot ≈ 0.4; rest ≈ 0.87 (без состояния resting); heal ≈ 0.65 (при 39% HP).

Вывод: **fish/gather/steal/break_in/pet_care/loot/rest/heal/socialize не имеют ни одного шанса**, пока в БД есть хоть один активный квест (а он есть всегда). Фаза 2 — мёртвый геймплей. Побочный симптом: питомец никогда не получает ухода вручную → цикл adopt → голод → pet_left (у Джозеца pet_left 3, pet_revived 7).

### B. Голодающий отдых → вечные «поражения» (критично)

- Герой **никогда не спит** (rest недостижим) → fatigue высокий, **sp = 0** → `FightAction`: атака ×0.8 при sp<=0 — постоянный штраф −20%.
- Бой стартует при HP > 30% — Джозец лезет в бой с 39% HP (heal недостижим, auto-consume пьёт зелья только ниже 30%).
- Итог: бои тянутся до лимита раундов → `max_rounds` = victory:false → журнал **hero_defeat 223** (реальных смертей мало — death_respawn 1), память героя копит поражения, Learner сдвигает caution/bravery.
- Сны (P-4) требуют streak resting ≥ 3 — при недостижимом rest → 2 сна за 14 дней, фича фактически выключена.

### C. Мозг: три реальных дефекта (построчная проверка 2026-09-05)

**C-1. Причуды о погоде — мёртвый код (двойной баг, `graph.ex` → `quirk_term/3`).**
Читается легаси `ctx.location.weather` (в dev-БД у всех локаций «Ясно», колонка не обновляется — источник правды теперь `ctx.weather` из ядра мира), и сравнивается с русскими display-именами («Гроза», «Дождь»), тогда как `ctx.weather` — ключи (`"rain"`, `"storm"`, `"snow"`). Ветка `:superstitious` и погодная половина `:afraid_of_water` не срабатывают никогда. Фикс: `ctx.weather` + ключи. (`intent.ex` читает погоду правильно — там ок.)

**C-2. `link_term/4` — константа для всех целей.**
Модификатор = `Σ(вес×черта_a×черта_b)/n × gain` по всем 15 связям сразу, один и тот же для каждой цели; `goal_name` попадает только в reason-строку. Для Джозеца: Σ = 0.911 → **+0.021 ко всем целям** (те самые «(0.02)» в decision_log). Слой «мозга» математически не дифференцирует цели, хотя пары генома имеют смысловые названия (`greed~dexterity: воровская жилка` и т.д.). Фикс: маппинг «пара черт → цели» (например, greed~dexterity усиливает steal/break_in, empathy~patience — pet_care, tenacity~patience — gather/fish) или пер-цельная свёртка.

**C-3. Обучение нейтрализуется гомеостазом (`learner.ex`).**
Бюджет пластичности 10 п./нед на ВСЕ черты (победа = 0.7 п.), а `return_to_base` тянет каждую черту к гено-базе на 0.02/тик → ~0.5–0.6/черв/нед при ~28 решениях/нед — того же порядка, что весь недельный бюджет. Дрейф связей ±0.01–0.015 в коридоре ±0.3 тоже мал. Итог: личность фактически заморожена у гено-базы; обучения-в-результате нет. Фикс: снизить `base_return` до ~0.002/тик или применять раз в игровой день.

**Проверено и НЕ buggy:** геном (детерминирован из байт, коллизия причуд 25/26 — редкая мелочь), `Personality.normalize` (строковые ключи JSONB — починено ранее), персист обучения (apply_result → learn → changeset), `Intent.world_stage` (ключи погоды, cap, «мертвые цели не воскрешаются»), рабочие причуды: spider_panic/dawn_fisher/night_thief/cup_collector/sweet_tooth/braggart.

### D. Нарратив не показывает реальные действия (сильно)

- `build_tags` не ставит тег для `state_to == "shopping"` (и looting) → ни одно событие не матчится → fallback `generic_action` → «Продолжает свой путь». **948 записей = в основном шопинг-тики квестовых collect-шагов** (в БД лежат 20 активных шаблонов `shop` — они просто не используются!). Плюс в городах нет ни одного explore-события (smell_flowers — только village).
- Флейвор-события (hear_wolves и т.п.) стреляют на каждом explore/travel-тике; dedup всего /3 → журнал забит «волками» вместо действий.

### E. Прогресс квеста «kill» считается по раундам, не по победам (баг)

`check_quest_progress` вызывается каждый тик с `FightAction` — каждый **раунд** многотикового боя инкрементирует progress. «Убей 5 волков» закрывается за один бой из 5 раундов.

### F. Мёртвый код в решениях

- `@location_profiles` (city → socializing 20 и т.д.) используются только легаси-`Action.score`, который FSM не вызывает — профили локаций не влияют на Utility AI.
- `Memory.travel_modifier`, `recent_emotions` — не читаются нигде в решениях.
- GOAP никогда не включает `:loot` ни в один план (complete_quest = explore/fight/shop/rest) — LootAction достижим только через цель loot, которая недостижима (см. A).

## 3. План лечения (предложение)

**Статус: Фаза 1 (мозг) ✅ + Фаза 2 (приоритеты/квест) ✅ + Фаза 3 (нарратив) ✅ — 291 passed, проверено live на Джозеце.**

Live-подтверждение (2026-09-06): при fatigue 100 Джозец ушёл в rest (utility 1.0), sp 0 → 60 за несколько тиков, в хронике появились rest_by_fire и сны (streak сработал). Дельты мозговых связей разные по целям (fight 0.05 / complete_quest 0.08).

1. **Безопасность важнее квеста** ✅: `needs_urgent` (fatigue > 75 / hp < 50%) → rest/heal +0.35, quest −0.3; конфиг `game_configs["needs_urgent"]` (дефолт в ContextBuilder).
2. **Разжирение квеста** ✅: base 0.7 → 0.45, tenacity ×0.0015, бонус за совпадение шага/локации (collect вне лавки теперь −0.2); travel-тяга квеста только если шаг невыполним на месте (вместо грубого стаба «любой город +0.5»); TravelAction выбирает локацию по типу шага (collect → city/village, kill → wilderness/dungeon).
3. **Окно активностей** ✅: после завершения квеста `activity_break_until_tick` (3–5 тиков) в state_data — auto_accept молчит в окне; маркер ставится через merged_sd (правило 2.1).
4. **Боевой цикл** ✅: rest и так восстанавливал sp (15/5, проверено) — герой просто не отдыхал; порог боя 0.3 → 0.45; GOAP: collect вне лавки → [:travel, :shop] вместо невыполнимого [:shop].
5. **Мозг** ✅: (C-1) причуды погоды → `ctx.weather` ключи; (C-2) связи по целям `@link_goals` + нормировка на число поддерживающих связей; (C-3) гомеостаз раз в игровой день (`brain.last_return_day`).
6. **Нарратив** ✅: теги shopping/looting/sleep + события `shop`/`loot` в NarrativeEvent (шаблоны в БД уже были: 20 shop / 17 loot); погодные теги NarrativeContext переведены на ключи ядра (легаси-«Ясно» больше не блокирует rain/snow/fog события).
7. **Баг kill-прогресса** ✅: инкремент только при combat_result (победа), раунды (combat_progress без result) не считаются.
