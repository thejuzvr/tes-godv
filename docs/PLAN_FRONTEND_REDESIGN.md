## Контекст

Beta-0.7 закрыта, бэкенд устойчив. Фронтенд — рабочий, но собран поспешно:
- **Тёмная тема генерична** (Tailwind slate, не связана с миром TES), по умолчанию — светлый Vercel-минимализм.
- **Geist Sans не имеет кириллицы** — русский текст рендерится системным фолбэком, смешанная типографика.
- **Заглушки в проде**: бейдж «placeholder» на Репутации с захардкоженными фракциями; компоненты `InventoryGrid` (defaultItems), `NeedsPanel` (potions=3), `ReputationPanel` (defaultReputations) содержат моки, дашборд их дублирует инлайн-копиями.
- **Модули расставлены нелогично**: инвентарь (владения) в правой колонке рядом с пультом бога; задание — под инвентарём; хроника (сердце игры) без соседства с заданием.
- **Инвентарь без названий** — только иконки, игрок не видит, что лежит в сумке.
- 403-шум в консоли от admin-проверки; canvas настроения рисует жёстким `#000`.

## Решения пользователя (зафиксированы)

1. **Скиллы**: anthropics `frontend-design` + vercel `web-design-guidelines` (установлены), плюс `ui-animation` и MCP (playwright/postgres/context7).
2. **Стиль**: тёмное фэнтези (атмосфера TES + современный вид).
3. **Стратегия**: по экранам, дашборд первым.
4. **Заглушки**: полный аудит + замена на реальные данные.

## Дизайн-система «Обсерватория» (F-0)

Предмет: ты — бог, наблюдающий жизнь героя в Тамриэле; хроника его жизни — центральный артефакт интерфейса. Всё тёмное — не «серверная», а **скрипторий при свечах**.

### Палитра (тёмная, по умолчанию) — «Ночной уголь»

| Токен | Значение | Имя | Применение |
|---|---|---|---|
| `--bg` | `#16110b` | Ночной уголь | фон страницы (тёплый, не синий) |
| `--surface` | `#1f1811` | Переплёт | панели |
| `--surface-raised` | `#2a2116` | Кожа | hover/вложенные ячейки |
| `--fg` | `#e6d9bd` | Пергамент | основной текст |
| `--muted` | `#a08e6f` | Выцветшие чернила | вторичный текст |
| `--border` | `#382d1e` | — | границы |
| `--accent` | `#c9a227` | Септим | золото: акценты, активные вкладки |
| `--hp` | `#c0392b` | Даэдрик | здоровье (как HUD TES) |
| `--mp` | `#3d7dc8` | Магицкая | магия |
| `--sp` | `#5a8a3c` | Стамина | **зелёная** (в TES стамина зелёная — сейчас янтарная) |
| `--xp` | `#8b5cf6` | Камень душ | опыт |
| `--gold` | `#d4a72c` | Септим-яркий | золото/лут |

Светлая тема — **«Пергамент»**: состаренная бумага `#f2ecdf`, чернильный текст `#2b2114`, то же септим-золото (темнее, `#8a6d1c`, для контраста). Переключатель темы получает смысл: **Свет/Тьма**, тёмная — по умолчанию.

### Типографика

| Роль | Шрифт | Применение |
|---|---|---|
| Display | **Cormorant Garamond** 600/700 (кириллица ✓) | логотип, имена, заголовки глав хроники, локация, задание |
| Body | **Inter** 400/500/600 (полная кириллица) | основной текст; заменяет Geist (без кириллицы) |
| Mono | **Fira Code** 400/500/600 (кириллица ✓) | данные, метки, время, значения |

Иконки: chrome-иконки интерфейса → `lucide-react` (уже в зависимостях). Эмодзи из данных БД (иконки предметов/питомцев) — остаются как данные.

### Компоновка дашборда (F-1)

```
┌────────────────────────────────────────────────────────────────┐
│ TES Idle   Панель · Пантеон · Аналитика · Wiki · [Админ]  ● ⚙  │
├────────────────────────────────────────────────────────────────┤
│ [Герой: имя, lvl, HP/MP/SP/XP, золото] [Локация+время] [Настр.]│  ← лента героя
├──────────────┬─────────────────────────────────┬───────────────┤
│ СОСТОЯНИЕ    │ АКТИВНОЕ ЗАДАНИЕ (компактно)    │ ВОЛЯ БОГА     │
│ Потребности  ├─────────────────────────────────┤ Пульт бога    │
│ Питомец      │ ХРОНИКА (сигнатурный модуль,    ├───────────────┤
│ Экипировка   │ максимум места)                 │ МИР           │
│ Инвентарь    │ «День 27. Тихий день»           │ погода/войны/ │
│ Репутация(ре)│ записи · мотивы · новости 📡    │ события       │
└──────────────┴─────────────────────────────────┴───────────────┘
│ связь · золото/ч · xp/ч · онлайн          автономный режим     │
```

Логика для игрока: слева — что герой **имеет**; в центре — что с ним **происходит**; справа — что **можешь сделать ты** (пульт) и что творится **в мире**. Мир переезжает из ленты в правую колонку (контента стало много — войны, события с TTL).

### Сигнатурный элемент — «Хроника-манускрипт» (F-2)

Журнал оформляется как иллюминированная хроника:
- заголовки глав — Cormorant Garamond italic + золотая линия с ромбом-разделителем;
- записи — «полоски веллума» с цветным левым кантом по типу события (воск);
- мотивы решений — курсивный «черновик на полях»;
- фильтры по **всем** типам записей (сейчас только 4 из ~12), без дубля даты;
- единый компонент JournalPanel — дубль в DashboardPage уничтожается.

Одна сигнатура — всё остальное дисциплинированно тихо. Тёплое свечение сверху страницы — на грани допустимого, не более 3–4% непрозрачности.

## Фазы (1 фаза = 1 тест)

- Шрифты: Inter + Cormorant Garamond (fontsource, кириллические сабсеты), Geist Sans удаляется.
- Палитра: тёмная «Ночной уголь» (default) + светлая «Пергамент» в `index.css`.

- MoodCanvas: цвета из CSS-переменных, не `#000`.
- `prefers-reduced-motion` для всех анимаций.
- **Тест F-0-T**: `npm run build` чисто; Playwright — обе темы на дашборде; скриншоты.

### F-1 «Дашборд: каркас»
- Перекомпоновка по схеме выше; лента героя вместо разрозненных панелей.
- Репутация — реальные данные из API (endpoint уточняется по аудиту), бейдж «placeholder» удаляется.
- Дубли компонентов (инлайн-копии DashboardPage) заменяются на общие из `components/` без дефолтных моков; мёртвые моки удаляются.
- 403-шум admin-проверки убирается (однократная проверка / тихий catch).
- **Тест F-1-T**: build + браузерный чек-лист всех зон дашборда.

### F-2 «Хроника» (сигнатурный модуль)
- Манускрипт-стиль журнала: главы, канты, мотивы, разделители.
- Фильтры по всем типам записей; чистый таймстемп.
- Единый JournalPanel (дубль в DashboardPage удалён).
- **Тест F-2-T**: живой WS-push новой записи в браузере; фильтры.

### F-3 «Функционально важные модули»
- Инвентарь: названия предметов, тултипы (имя/тип/редкость/статы/вес), подсветка редкости.

- Замена всех найденных аудитом заглушек реальными данными (отчёт аудита прикладывается перед фазой).

### F-4 «Остальные страницы»

- **Тест F-4-T**: build + проход по всем роутам в браузере.

### F-5 «Полировка и приёмка»

## Аудит (результаты, 03.09) — интегрировано в фазы

- **Репутация**: реальные данные живут в `state_data["law"]` (LawSystem) — фейковая панель заменяется на данные из hero_update/state_data (F-1).
- **19 API-методов не используются**: интерактив с предметами (`useItem/dropItem/equipItem/unequipItem`), квестами (`generateQuest/acceptQuest/completeQuest`), путешествия (`getLocations/travel`), предложения (`createSuggestion`) — входит в объём F-3.
- **12 файлов-сирот** в `components/` с дефолтными моками (InventoryGrid, QuestPanel, LocationPanel, GameTimePanel, MoodGraph, GodPanel, NeedsPanel, ReputationPanel, HeroStatus, JournalPanel-дубль, ui/Panel, ui/StatBar) — расчистка в F-1/F-2: живые реализации переезжают из DashboardPage в components/, сироты удаляются.
- **WS `combat_result`** пушится бэком, фронтом не обрабатывается — финал боя не виден (F-1).
- **`--bg-elevated` используется 19 раз, не определён**; `onlineCount`/`isLoading` — мёртвые срезы store; `hero.bounty` («В розыске») нигде не показан; XP/ч считается от накопленного XP — всё в F-1.
- **Tailwind 4 без `@theme`** — цветовые утилиты не генерируются; 576 инлайн-стилей; lucide-react/recharts установлены и не используются (F-0/F-5).
- **F-4**: в Пантеоне золото форматируется как «₽»; Wiki-редактор сохраняет только в localStorage; 0 media-запросов во всём фронтенде — responsive в F-5.
- Ассеты `hero.png`, `react.svg`, `vite.svg` — мёртвые; удаляются в F-5.
