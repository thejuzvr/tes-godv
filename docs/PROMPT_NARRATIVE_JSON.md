# Промпт для генерации JSON-массива шаблонов нарративов через AI

Этот файл — инструкция для генерации новых шаблонов «словника» нарративов
через любую LLM (ChatGPT, Claude, DeepSeek…). Скопируйте **Промпт** в AI,
полученный JSON вставьте в мастерскую: **Словник → «📥 Импорт JSON»** (или
в админку). Шаблоны из импорта идут на модерацию (`source="community"`).

---

## Промпт (скопировать целиком в AI)

Ты — автор игровых нарративов для idle-RPG в мире The Elder Scrolls V: Skyrim
(русский язык). Твоя задача — сгенерировать **JSON-массив шаблонов** для
движка нарративов. Ответ должен быть ТОЛЬКО JSON-массивом, без пояснений,
без markdown-обёртки ```json.

### Формат каждого элемента массива

```json
{ "template_type": "explore", "text_template": "В тени {landmark} герой {hero_name} обнаружил {discovery}." }
```

Ровно два ключа: `template_type` (строка из списка ниже) и `text_template`
(строка на русском). Другие ключи не добавлять.

### Типы шаблонов (выбирай только из них)

- Бой: `combat_start`, `combat_result`, `hero_victory`, `hero_defeat`, `combat_defeat`, `enemy_ambush`, `spot_bandits`
- Дорога: `travel`, `travel_road`, `travel_shortcut`, `leave_city`, `enter_city`, `bad_weather`, `avoid_danger`, `search_danger`
- Исследование и находки: `explore`, `discover_ruin`, `discover_treasure`, `find_loot`, `loot`, `find_abandoned_cart`, `find_tracks`, `notice_tracks`, `hear_river`, `hear_birds`, `smell_flowers`, `equip`
- Отдых и мысли: `rest`, `rest_by_fire`, `sleep_in_inn`, `dream`, `thought`, `feel_confident`
- Общество и торговля: `social`, `meet_merchant`, `learn_rumors`, `hear_song`, `shelter_from_storm`, `shop`
- Смерть и мир: `death`, `death_respawn`, `remember_defeat`, `world_news`
- Гильдии: `guild_founded`, `guild_levelup`, `guild_feast`, `guild_shop_purchase`
- Активности: `fishing`, `gather`, `collect_herbs`, `steal`, `break_in`, `jail`, `pet_care`
- Кузня и боги: `enhance_success`, `god_encourage`, `god_punish`, `god_heal`, `god_direct`, `god_quest`, `god_weather`

### Переменные `{...}` — подставляй только те, что перечислены для типа

**Любой тип:**
`{hero_name}` — имя героя (им. падеж); `{location_name}` — локация (им.); `{mood}` — число 0–100; `{god_name}` — имя бога (им.).

**Бой** (`combat_start/result`, `hero_victory/defeat`, `combat_defeat`, `enemy_ambush`, `spot_bandits`):
`{monster_name}` — имя монстра (им., напр. «Серый волк»); `{xp}` — число; `{gold}` — число; `{rounds}` — число; `{_combat_verbs}` — глагол боя в прошедшем времени (напр. «Сразился»).

**Дорога** (`travel*`, `avoid_danger`, `search_danger`):
`{destination}` — пункт назначения (им., напр. «Вайтран»); `{terrain}` — местность (дат. падеж, напр. «густому лесу»); `{landmark}` — ориентир (род. падеж, напр. «старого дуба»).

**Находки** (`explore`, `discover_*`, `find_loot`, `loot`, `shop`):
`{discovery}` — находка (вин. падеж, напр. «старую карту»); `{item_name}` — предмет (им.); `{loot_text}` — описание добычи (вин., напр. «немного золота»); `{gold_spent}` — число.

**Общество** (`social`, `meet_merchant`, `learn_rumors`):
`{npc_name}` — имя NPC (им., напр. «Олаф»); `{gamble_result}` — итог игры (напр. «выиграл 15 золотых»).

**Активности:**
- `fishing`: `{fish_name}` — улов (вин., напр. «ловкую форель»)
- `gather`, `collect_herbs`: `{herb_name}` — собранное (вин., напр. «пучок лаванды»)
- `steal`: `{stolen_gold}` число; `{witness_name}` имя свидетеля (им.); `{bounty_gold}` число
- `break_in`: `{stolen_gold}`, `{trap_hp}` число (урон), `{witness_name}`
- `jail`: `{jail_reason}` причина (род. падеж, напр. «кражу» — текст «за {jail_reason}»); `{jail_ticks}` число
- `pet_care`: `{pet_name}` имя (им.); `{pet_species}` вид (им.); `{pet_care_kind}` действие в прошедшем времени (напр. «покормил»); `{pet_loyalty}` число 0–100

**Возрождение** (`death_respawn` только): `{location}` — город (им.); `{generation}` число.

**Питомцы 15 видов (для `pet_care` можно упоминать вид):** волк, сова, кот,
ящерица, коза, лиса, ворон — обычные; гусь, ёжик, мотылёк, камень, репка,
масло, скелет, сыр — комичные. Камень не голодает и молчит, сыр «скисает»,
гусь агрессивен и сам кидается в бой.

### Правила текстов (обязательные)

1. **Падежи переменных.** Подставляемые значения всегда в указанном падеже:
   «Присел у {landmark}» — верно (род.); «Присел у {landmark}и» — нельзя.
   Строй фразу так, чтобы после подстановки конкретного значения падеж не ломался.
2. **Переменные только из списка типа.** Незнакомая переменная останется дыркой
   `{var}` в живом тексте — это баг. Если не уверен — пиши без неё.
3. **Длина:** 60–140 символов, одно-два предложения.
4. **Тональная смесь ~50/50:** половина строк — атмосферно-серьёзные
   («Дождь стучал по капюшону всю дорогу»), половина — комичные с сухим юмором
   («Камень, похожий на хлеб, вкуснее, чем выглядит»). Тон комичных —
   ненавязчивый, без анекдотов и поучений.
5. **Мир Скайрима:** таверны, стража, драконы, гильдии, тундра, снег.
   Не упоминать современность, реальную политику, другие франшизы.
6. **Без обращения к игроку.** Текст — третье лицо: «{hero_name} сделал…»,
   не «вы сделали».
7. **Без повторов:** ни одна строка не должна дублировать другую дословно.
8. **Шаблон не самодостаточен без переменной:** переменная должна вписываться
   естественно, а не «где-нибудь воткнуть».

### Что выдать

Сгенерируй массив из **N шаблонов** (число укажет пользователь; если не указано —
30): для каждого выбранного типа по 2–4 строки, тональная смесь соблюдена.
Ответ — только JSON-массив, без markdown и пояснений.

```
Сгенерируй 10 игровых шаблонов-предложений для idle-RPG (мир Skyrim, русский).
Формат ответа — ТОЛЬКО JSON-массив:
[{"template_type": "explore", "text_template": "..."}]

Переменные (можно вставлять в текст): {hero_name} имя героя, {discovery} находка

```

## После генерации — чек-лист перед импортом

1. ✅ Это JSON-массив, начинается `[` и заканчивается `]`, без ``` обёрток.
2. ✅ Каждый элемент имеет ровно `template_type` и `text_template`.
3. ✅ Значения `template_type` есть в списке типов (иначе движок не подберёт
   шаблон — тип станет «мёртвым»).
4. ✅ В тексте нет переменных вне списка типа (случайные `{x}` останутся в
   живой хронике).
5. ✅ Падежи при подстановке примеров не ломаются — прогоните мысленно:
   «Подошёл к {terrain}» + «густому лесу» = «Подошёл к густому лесу» ✔.
6. ✅ Нет дословных дублей — импорт их отклонит («Already exists»).
