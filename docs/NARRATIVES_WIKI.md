# TES Idle — Narrative Variables Reference (WIKI)

## Формат переменных

Все переменные используют фигурные скобки: `{variable_name}`

Пример шаблона:
```
У {landmark} путь преградил {monster_name}. Герой схватился за клинок — бой начался. {combat_result}
```

## Фильтры шаблонов

Шаблоны в БД можно фильтровать по:

| Поле | Описание | Пример |
|------|----------|--------|
| `template_type` | Тип шаблона | "combat", "explore" |
| `location_id` | Привязка к локации (null = универсальный) | UUID или null |
| `mood_min` | Мин. настроение | 0.0 |
| `mood_max` | Макс. настроение | 100.0 |
| `is_active` | Активен ли шаблон | true/false |
| `source` | Источник | "system", "llm", "community" |

## JSON-формат импорта

Для импорта шаблонов через «Словник нарративов» используйте JSON массив объектов:

```json
[
  {"template_type": "combat", "text_template": "У {landmark} путь преградил {monster_name}. Герой схватился за клинок — бой начался. {combat_result}"},
  {"template_type": "explore", "text_template": "Сквозь густую чащу пробивался слабый свет. Герой обнаружил {discovery}."}
]
```

**Поля:**
- `template_type` — тип шаблона (обязательно)
- `text_template` — текст шаблона с переменными (обязательно)
- `source` — источник (по умолчанию "community")

**Примечание:** При импорте шаблоны автоматически проверяются на дубликаты и валидность.

## Godville vs TES Idle — Сравнение переменных

| Godville | TES Idle | Описание |
|----------|----------|----------|
| `%hero_name%` | `{hero_name}` | Имя героя |
| `%monster%` | `{monster_name}` | Имя монстра |
| `%current_town%` | `{location_name}` | Текущий город |
| `%nearby_town%` | `{landmark}` | Ближайший ориентир |
| `%gold%` | `{gold_amount}` | Золото |
| `%hp%` | `{hero_hp}` | Здоровье |
| `%pet_name%` | — | Нет питомцев |
| `%hero_guild%` | — | Нет гильдий |
| `%current_quest%` | `{quest_name}` | Текущий квест |
| `%motto%` | — | Нет девиза |
| `%random_skill%` | — | Нет умений |
| `%some_territory%` | `{terrain}` | Местность |
| `%some_tavern%` | — | Нет таверн |
| `%artifact%` | `{item_name}` | Предмет |
| `%hero_equipment%` | — | Нет экипировки в нарративах |
| `%rg%` | `{god_name}` | Обращение к богу |

## Примеры шаблонов

### Combat
```
У {landmark} путь преградил {monster_name}. Герой схватился за клинок — бой начался. {combat_result}
{monster_name} выскочил из засады у {landmark}, раздав рёв. {combat_result}
Тени сгустились, и {monster_name} атаковал без предупреждения. {combat_result}
```

### Explore
```
Сквозь густую чащу пробивался слабый свет. Герой обнаружил {discovery}.
Тропа привела к неожиданному месту — {discovery}.
На краю {terrain} обнаружилось нечто интересное: {discovery}.
```

### Shop
```
Торговец {npc_name} расхваливал товары. Купил {item_name} за {gold_spent} золотых — припасы пополнены.
В лавке {npc_name} нашёл нужные зелья. Заплатил {gold_spent} золотых.
```

### Social
```
В таверне пахло элем и жареным мясом. Трактирщик {npc_name} налил кружку эля без лишних вопросов.
В таверне сыграл партию в кости с {npc_name}. {gamble_result}
```

### Rest
```
Костёр потрескивал, разгоняя вечерний холод. Герой закинул руки за голову и привалился к стволу дерева. Раны затягивались, силы возвращались.
```

### Travel
```
Дорога петляла среди холмов, и ветер нёс запах хвои. Герой шагал вперёд, не оборачиваясь. Путь ещё долог.
```

### Death
```
Мир потускнел на мгновение... а потом — свет. Герой очнулся у алтаря, потеряв немного золота. Смерть — не конец.
```

### Quest
```
Герой взял задание «{quest_name}». Приступаю к выполнению.
Герой завершил задание «{quest_name}»! Награда: {quest_xp_reward} XP, {quest_gold_reward} золота.
```
