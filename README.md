# ⚔️ TES Idle — The Elder Scrolls God-RPG

**Автономная текстовая RPG в мире Древних Свитков, вдохновлённая философией Godville.**  
*Герой живёт собственной жизнью: странствует по Скайриму, сражается с чудовищами, торгуется, нарушает закон и заводит питомцев. Игрок выступает в роли высшего божества — наблюдает за хроникой через пергаментный журнал и направляет судьбу подопечного знамениями и чудесами.*

## 🌟 Ключевые особенности

### 🧠 1. Автономный искусственный интеллект героя
* **Трёхуровневая модель принятия решений**:
  * **Utility AI** — динамический расчёт актуальности 14 различных целей героя (лечение, отдых, квесты, бой, лавка, побег).
  * **GOAP (Goal-Oriented Action Planning)** — построение цепочек действий под меняющийся мир (например: *нет стрел в подземелье → путь в город → посещение торговца → возвращение*).
  * **FSM** — строгие стейт-машины состояний (*idle, explore, combat, travel, jailed, fishing, resting*).
* **Геном личности (`BrainHash`)**:
  * Каждому герою при рождении генерируется детерминированный слепок личности (SHA-256): 6 базовых черт характера, предрасположенности и индивидуальные причуды (*quirks*).
  * Система **Learner** обеспечивает естественный дрейф характера и обучаемость героя на основе прожитых побед, поражений и травм.

### 📜 2. Процедурный нарративный движок (The Chronicler)
* **Более 1190 контекстных шаблонов в 54 категориях событий**:
  * Никаких одинаковых строк: в журнале органично чередуются боевой пафос, ироничные зарисовки и атмосфера сурового Тамриэля.
* **Сборка сцен (Composer)**:
  * Каждая запись динамически комбинируется: `[Погодный опенер ядра мира]` + `[Костяк действия]` + `[Реакция на воспоминание / причуда / настроение]`.
* **Пул фрагментов (`FragmentPool`)**:
  * 200+ описательных фрагментов с правильными падежными окончаниями для ориентиров, реликвий, трофеев, рыб и трав.

### ⚡ 3. Божественный пантеон и вмешательства
* **Небесная прана**: накапливается по мере свершений героя и славы в храмах.
* **6 видов чудес**:
  * 🌟 **Вдохновить** — поднять боевой дух и настроение.
  * ⚡ **Наказать** — небесная кара для острастки и исправления грехов.
  * 💚 **Исцелить** — срочное закрытие смертельных ран прямо посреди битвы.
  * 🌧️ **Погода** — призыв бури или рассеивание туч над провинцией.
  * 🧭 **Направить** — подсказка верного пути заблудившемуся герою.
  * 📜 **Квест** — ниспослание священного поручения от божества.

### 🛡️ 4. Оплот Соратников (Система Гильдий)
* **Монументальное знамя**: геральдический герб, девиз ордена, прогресс ранга гильдии и общее знамя соратников.
* **4 полноэкранных зала**:
  * 🔥 **Алтарь и Казна** — подношения золота Девяти во имя бафов опыта и силы, казна ордена и закатывание общих хмельных пиров.
  * 🛒 **Лавка соратников** — покупка уникальной экипировки и зелий за заработанные очки верности.
  * 👥 **Зал соратников** — табель о рангах, управление офицерами, рассмотрение прошений и приём рекрутов.
  * 💬 **Ратуша и Вести** — живой чат гильдии с мягким кулдауном и мировая хроника свершений всех орденов Тамриэля.

### 🗺️ 5. Интерактивная векторная карта Скайрима (`/map`)
* Полноэкранный SVG-холст с топографической проекцией провинции.
* Реальные координаты всех холдов, городов, фортов, руин и лагерей.
* Отображение текущего местоположения героя, трассировка пути в реальном времени, сводка погоды и экономических цен в поселениях.

### ⚖️ 6. Законы, преступления и тюрьмы (Law System)
* Преступления (воровство, взлом, нападения) генерируют персональную награду за голову (**Bounty**) в конкретном владении.
* Система свидетелей и ареста стражей: попавшись, герой отправляется в городскую темницу.
* Варианты выхода: честная отсидка срока, взятка стражникам или рискованный ночной побег.

### 🐾 7. Питомцы, сны и смерть
* **15 видов верных спутников**: от грозных саблезубов и волков до комичных боевых гусей и полированных камней-питомцев.
* **Фазы отдыха и сновидений**: во время ночлега у костра герой видит сюрреалистичные сны, отражающие пережитые события.
* **Двухфазная смерть**: гибель не удаляет персонажа, а отправляет дух к святилищу ближайшего города для возрождения с новым поколением.

## 🚀 Быстрый старт

### Требования к окружению
* **Elixir** `>= 1.20` и **Erlang/OTP** `>= 26`
* **Node.js** `>= 20` и **npm**
* **PostgreSQL** `>= 15` (по умолчанию база `tes_idle_dev`)

### ⚡ Запуск в один клик (Windows)
В корневой папке проекта находится настроенный скрипт:
```cmd
start.bat
```
Скрипт автоматически запустит Elixir Phoenix API на порту `4000` и React Vite фронтенд на порту `5173`.

---

### 🛠️ Пошаговый ручной запуск

#### 1. Клонирование и настройка бэкенда
```bash
cd tes_idle_elixir

# Установка зависимостей Elixir
mix deps.get

# Создание базы данных и накат миграций
mix ecto.setup

# Запуск первичных сидов (нарративы, мир, магазины, предметы)
mix run priv/seed_all.exs

# Запуск Phoenix сервера
mix phx.server
```
> Бэкенд будет доступен по адресу: `http://localhost:4000` (API: `http://localhost:4000/api/v1`)

#### 2. Запуск фронтенда
```bash
cd ../frontend

# Установка npm зависимостей
npm install

# Запуск в режиме разработки с HMR
npm run dev
```
> Веб-приложение откроется по адресу: `http://localhost:5173`

## 🎨 Дизайн-система «The Imperial Chronicler»

Интерфейс спроектирован в эстетике средневекового императорского скриптория с глубокой проработкой деталей:

* **Мониторный десктопный грид (до 1840px)**: отсутствие пустых боковых полей на экранах 1080p+, адаптивные многоколоночные витрины гильдии и карты.
* **Две аутентичные темы с идеальным контрастом**:
  * 📜 **«Пергамент» (Светлая)** — состаренная пергаментная бумага, тёмно-коричневые железо-галловые чернила, сепия и латунные акценты.
  * 🌑 **«Ночной уголь» (Тёмная)** — глубокий тон ночного скриптория при свечах, золочённое тиснение и приглушённая кожа.
* **Шрифтовая триада**:
  * *Cormorant Garamond* — благородные заголовки и геральдика.
  * *Inter* — чистый, легко читаемый интерфейсный текст.
  * *Fira Code* — моноширинные числовые показатели, статы и системные логи.
