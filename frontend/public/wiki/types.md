# Типы шаблонов

Каждый шаблон имеет тип (`template_type`), который определяет, когда он используется.

## Основные типы

| Тип | Описание | Когда используется |
|-----|----------|-------------------|
| `explore` | Исследование | Состояние `exploring` |
| `rest` | Отдых | Состояние `resting` |
| `shop` | Покупки | Состояние `shopping` |
| `social` | Общение | Состояние `socializing` |
| `travel` | Путешествие | Состояние `traveling` |
| `loot` | Добыча | Состояние `looting` |
| `death` | Смерть | Состояние `dead` |
| `thought` | Мысли | Случайные мысли героя |
| `equip` | Экипировка | Когда герой надевает предмет |

## Типы боя

Бой происходит в несколько тиков (1 тик = 1 раунд). Шаблоны используются для начала и результата боя.

| Тип | Описание | Когда используется |
|-----|----------|-------------------|
| `combat_start` | Начало боя | Когда монстр обнаружен |
| `combat_result` | Результат боя (победа) | Когда монстр повержен |
| `combat_defeat` | Поражение героя | Когда герой погибает |

### Переменные для боевых шаблонов

**combat_start:**
- `{monster_name}` — имя монстра

**combat_result:**
- `{hero_name}` — имя героя
- `{monster_name}` — имя монстра
- `{rounds}` — количество раундов
- `{xp}` — полученное XP
- `{gold}` — полученное золото

**combat_defeat:**
- `{hero_name}` — имя героя
- `{monster_name}` — имя монстра

## Типы бога

Каждая кнопка Пульта бога использует свой тип:

| Тип | Кнопка |
|-----|--------|
| `god_encourage` | Вдохновить |
| `god_punish` | Наказать |
| `god_heal` | Исцелить |
| `god_direct` | Направить |
| `god_quest` | Задание |
| `god_weather` | Погода |

## Источники шаблонов

| Источник | Описание |
|----------|----------|
| `system` | Дефолтные шаблоны из seed |
| `llm` | Сгенерированные LLM (требуют модерации) |
| `community` | Предложения игроков (требуют модерации) |
| `manual` | Созданы вручную через админку |
