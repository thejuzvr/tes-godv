# AI-генерация нарративов

## Как это работает

Вы можете использовать AI для генерации шаблонов нарративов. Выберите стиль, тип и количество — система сгенерирует промпт для ChatGPT/Claude.

## Стили

| Стиль | Описание |
|-------|----------|
| Стандартный | Нейтральное RPG-повествование |
| Атмосферный | Поэтичный, с акцентом на окружение |
| Комичный | Ирония, мемы из TES |
| Тёмное фэнтези | Мрачно, кровь, отчаяние |

## Процесс

1. Выберите стиль генерации
2. Выберите тип нарратива (бой, исследование и т.д.)
3. Укажите количество шаблонов
4. Скопируйте сгенерированный промпт
5. Вставьте в AI (ChatGPT, Claude, и т.д.)
6. Получите JSON массив шаблонов
7. Проверьте качество
8. Импортируйте через «Словник нарративов»

## Важно

- Все шаблоны проходят модерацию перед добавлением в игру
- Используйте переменные в фигурных скобках
- Только русский язык
- Без эмодзи
