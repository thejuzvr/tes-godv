# Доска предложений

## Как предложить нарратив

Если у вас есть идеи для нарративов — вы можете предложить их через доску предложений.

### Шаги

1. Перейдите в раздел «Предложения» на панели управления
2. Нажмите «Предложить»
3. Выберите тип нарратива
4. Напишите текст шаблона
5. Отправьте

### Требования к шаблонам

- 2-4 предложения
- Используйте переменные: `{hero_name}`, `{monster_name}`, `{item_name}` и др.
- Без хардкода конкретных локаций
- Только русский язык
- Без эмодзи

## Модерация

Все предложения проходят модерацию перед добавлением в игру. Администратор проверяет:

- Качество текста
- Соответствие стилю игры
- Правильность использования переменных
- Отсутствие дубликатов

После одобрения шаблон автоматически добавляется в игру.
