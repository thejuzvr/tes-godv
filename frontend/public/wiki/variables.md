# Все переменные нарративов

Полный список переменных, доступных в шаблонах нарративов.

---

## Герой (доступны везде)

| Переменная | Описание | Пример |
|------------|----------|--------|
| `{hero_name}` | Имя героя | `Дракенфел` |
| `{location_name}` | Название локации | `Ривервуд` |

> Переменные `{hero_name}` и `{location_name}` автоматически передаётся во все шаблоны.

## Бой (combat)

| Переменная | Тип | Описание | Пример |
|------------|-----|----------|--------|
| `{monster_name}` | string | Имя монстра | `Серый волк` |
| `{landmark}` | string | Ориентир (рандом из LANDMARKS) | `ворот города` |
| `{combat_result}` | string | Результат боя (сформирован из combat data) | `Вступил в бой. Четыре удара — и враг рухнул на землю. +20 XP, +10 золота.` |
| `{result}` | string | **Алиас** `{combat_result}` (для старых шаблонов) | — |
| `{hero_damage}` | int | Урон героя за весь бой | `15` |
| `{monster_damage}` | int | Урон монстра за весь бой | `8` |
| `{combat_rounds}` | int | Количество раундов боя | `3` |

### Данные combat (из state_machine.py)

```python
combat = {
    "monster_name": monster.name,      # str
    "hero_damage": total_hero_damage,   # int
    "monster_damage": total_monster_damage,  # int
    "victory": True/False,              # bool
    "rounds": rounds,                   # int
    "xp": xp_gain,                      # int (только при победе)
    "gold": gold_gain,                  # int (только при победе)
}
```

## Система боя

Бой происходит в несколько тиков (1 тик = 1 раунд):

1. **Начало боя** — journal entry с шаблоном `combat_start`
2. **Раунды** — каждый тик: герой бьёт → монстр бьёт → обновляется HP
3. **Результат** — journal entry с шаблоном `combat_result` (победа) или `combat_defeat` (поражение)

### Прогрессия

- **Логарифмический рост статов** — характеристики растут быстро на ранних уровнях, потом замедляются
- **Масштабирование монстров** — монстры масштабируются с уровнем героя (+3% HP/level, +2% attack/level)
- **Экипировка** — основной источник силы (+30-50 attack для легендарного оружия)

| Переменная | Тип | Описание | Пример |
|------------|-----|----------|--------|
| `{loot_text}` | string | Текстовое описание добычи | `15 золотых монет` / `Зелье здоровья (среднее)` |

### Формирование loot_text

```python
# Золото:
loot_text = f"{loot['amount']} золотых монет"

# Предмет:
loot_text = loot.get("name", "предмет")
```

### Данные loot (из state_machine.py)

```python
# Золото:
loot = {"type": "gold", "amount": 15}

# Предмет:
loot = {"type": "item", "name": "Зелье здоровья (среднее)", "icon": "🧪"}
```

## Источник данных

Все переменные берутся из `narrative_engine.py`:

- **TERRAINS** (7 вариантов) — строки 26
- **DISCOVERIES** (10 вариантов) — строки 27-38
- **LANDMARKS** (8 вариантов) — строка 39
- **SHOPKEEPERS** (7 имён) — строка 43
- **TAVERNERS** (7 имён) — строка 44
- **COMBAT_VERBS** (4 варианта) — строка 40

NPC имена выбираются случайно из пулов. Не используйте `{npc_name}` как фиксированное имя — оно будет разным каждый раз.
