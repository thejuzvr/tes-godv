# Гайд по написанию шаблонов

## Принципы хорошего нарратива

1. **Атмосферный** — создаёт образ, а не просто сообщает факт
2. **Короткий** — 2-4 предложения, не больше
3. **С переменными** — используйте `{monster_name}`, `{item_name}` и др.
4. **Без хардкода имён** — не пишите «Ривервуд» в тексте, используйте `{location_name}`
5. **Без CJK символов** — только русский текст

## Примеры

### Плохо

```
Герой убил волка.
```

### Хорошо

```
У {landmark} путь преградил {monster_name}. Герой схватился за клинок — бой начался. {combat_result}
```

### Плохо

```
Герой нашёл зелье.
```

### Хорошо

```
Среди трофеев: {loot_text}. Неплохой день для приключений.
```

## JSON-формат для импорта

Для массового импорта используйте JSON массив объектов:

```json
[
  {"template_type": "combat", "text_template": "У {landmark} путь преградил {monster_name}."},
  {"template_type": "explore", "text_template": "Герой обнаружил {discovery}."}
]
```

## Импорт через AI

1. Выберите стиль и тип в разделе «AI-генерация»
2. Скопируйте промпт
3. Вставьте в ChatGPT/Claude
4. Получите JSON массив
5. Импортируйте через «Словник нарративов»
