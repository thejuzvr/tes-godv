# Нарративы и переменные

Все нарративы хранятся в базе данных и управляются через админ-панель.

## Формат шаблона

Шаблон — это строка с переменными в фигурных скобках:

```
У {landmark} путь преградил {monster_name}. Герой схватился за клинок — бой начался. {combat_result}
```

## Доступные переменные

### Герой

| Переменная | Описание |
|------------|----------|
| `{hero_name}` | Имя героя |
| `{hero_level}` | Уровень |
| `{hero_hp}` | Текущее HP |
| `{hero_race}` | Раса |
| `{hero_class}` | Класс |
| `{hero_gold}` | Золото |
| `{hero_mood}` | Настроение (0-100) |

### Локация

| Переменная | Описание |
|------------|----------|
| `{location_name}` | Название локации |
| `{weather}` | Погода |
| `{terrain}` | Местность |
| `{landmark}` | Ориентир |
| `{discovery}` | Находка |

### Монстр (combat)

| Переменная | Описание |
|------------|----------|
| `{monster_name}` | Имя монстра |
| `{combat_result}` | Результат боя |
| `{hero_damage}` | Урон героя |
| `{monster_damage}` | Урон монстра |

### Предмет (shop/loot)

| Переменная | Описание |
|------------|----------|
| `{item_name}` | Название предмета |
| `{loot_text}` | Описание добычи |
| `{gold_spent}` | Потраченное золото |

### NPC

| Переменная | Описание |
|------------|----------|
| `{npc_name}` | Имя NPC |
| `{gamble_result}` | Результат игры в кости |

### Бог

| Переменная | Описание |
|------------|----------|
| `{god_name}` | Имя бога |
